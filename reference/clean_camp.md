# clean recode beneficiary camp

clean recode beneficiary camp

## Usage

``` r
clean_camp(x, col_name = "ben_camp", partner_col = "reforgp")
```

## Arguments

- x:

  dataframe

- col_name:

  character column with camp names, defaults to 'ben_camp'

- partner_col:

  character column with partner organization names, defaults to
  'reforgp'

## Value

dataframe

## Examples

``` r
if (FALSE) clean_camp(x, col_name = "ben_camp", partner_col = "reforgp") # \dontrun{}
```
