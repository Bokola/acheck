# Export/write gtsummary output to excel workbook

Export/write gtsummary output to excel workbook

## Usage

``` r
export_to_excel_formatted(
  list_of_objects,
  file_name = paste0("UNOCHA_Summary_Report_", Sys.Date(), ".xlsx")
)
```

## Arguments

- list_of_objects:

  list of `gtsummary` object

- file_name:

  character. output filename and associated path

## Examples

``` r
if (FALSE) export_to_excel_formatted() # \dontrun{} 
```
