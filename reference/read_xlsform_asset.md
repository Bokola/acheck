# read an xlsform file and compile it into a kobo asset metadata list

read an xlsform file and compile it into a kobo asset metadata list

## Usage

``` r
read_xlsform_asset(xlsform_path)
```

## Arguments

- xlsform_path:

  character. path to your local xlsform .xlsx or .xls file

## Value

a named list structured exactly like a robotoolbox kobo_asset object
