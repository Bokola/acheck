# Export a list of dataframes to word

Export a list of dataframes to word

## Usage

``` r
export_list_to_word(table_list, doc_path)
```

## Arguments

- table_list:

  list of dataframes

- doc_path:

  character vector of output directory

## Examples

``` r
if (FALSE) export_list_to_word() # \dontrun{}
```
