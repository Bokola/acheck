# run sampling schemes

run sampling schemes

## Usage

``` r
run_sample(
  df_frame,
  df_sample_n,
  dir = Sys.getenv("dir_unocha"),
  type = "PDM",
  name = "FDG"
)
```

## Arguments

- df_frame:

  dataframe of sampling frame

- df_sample_n:

  dataframe of sample size

- dir:

  charcter. of output path

- type:

  charcter. monitoring stage

- name:

  charcter. file name for otput

## Examples

``` r
if (FALSE) run_sample() # \dontrun{}
```
