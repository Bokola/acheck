# convert and label an excel export using xlsform workbook sheets

convert and label an excel export using xlsform workbook sheets

## Usage

``` r
label_with_xlsform(data_df, xlsform_path)
```

## Arguments

- data_df:

  data.frame. the raw exported kobo data with label headers (df)

- xlsform_path:

  character. path to your local xlsform .xlsx workbook

## Value

a clean data frame with code headers and labeled categorical values
