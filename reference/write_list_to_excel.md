# export a named list of data frames to an excel workbook

export a named list of data frames to an excel workbook

## Usage

``` r
write_list_to_excel(df_list, file_path)
```

## Arguments

- df_list:

  a named list of data frames

- file_path:

  character string for the output path

## Examples

``` r
if (FALSE) write_list_to_excel() # \dontrun{}
```
