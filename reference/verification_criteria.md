# Target beneficiary verification criteria and indicators dataset

A structured dataset containing the core humanitarian vulnerability
criteria alongside their corresponding assessment indicators tracked
during household survey evaluations.

## Usage

``` r
verification_criteria
```

## Format

A tibble data frame with 17 rows and 2 columns:

- Criteria:

  Character categorization of the target vulnerability group

- Indicator:

  Specific operational metric tracked during household data collection

## Source

Internal evaluation survey records
