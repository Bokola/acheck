# find partial matches between focal and beneficiary

find partial matches between focal and beneficiary

## Usage

``` r
get_partial_matches(df, focal = "focal_name", beneficiary = "benef_name")
```

## Arguments

- df:

  dataframe

- focal:

  character vector of focal variable

- beneficiary:

  character vector of beneficiary variable

## Value

a dataframe

## Examples

``` r
if (FALSE) get_partial_matches() # \dontrun{}
```
