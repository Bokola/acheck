# visualize parts to whole using a donut layout framework

visualize parts to whole using a donut layout framework

## Usage

``` r
plot_parts_donut(data, fill_col, palette = c("#81C784", "#FFB74D", "#E65100"))
```

## Arguments

- data:

  dataframe

- fill_col:

  character. the categorical column to slice

- palette:

  character vector. hex color values

## Value

a ggplot object

## Examples

``` r
if (FALSE) plot_parts_donut() # \dontrun{}
```
