# UNOcha survey choices

UNOcha survey choices

## Usage

``` r
choices
```

## Format

A tibble data frame with 17 rows and 2 columns:

- name:

  character. question name

- label:

  character. question label

- county:

  character. county

- subcounty:

  character. subcounty

- ward:

  character. ward

- sublocation:

  character. sublocation

- enum_egency:

  character. agency

Internal survey
