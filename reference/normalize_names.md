# Normalize a Name Vector

Cleans a character vector of names by collapsing extra whitespace,
trimming leading/trailing spaces, and converting to title case.

## Usage

``` r
normalize_names(x)
```

## Arguments

- x:

  A character vector of names.

## Value

A cleaned character vector.

## Examples

``` r
if (FALSE) normalize_names() # \dontrun{}
```
